# Python, IA y Mobile 
## Módulo I: Fundamentos y Lógica de Programación

### Semana 1: Introducción a la Sintaxis y Algoritmos
•	**Lunes:** Instalación en Ubuntu, uso de la terminal y print("Hola Mundo").  
•	**Martes:** Tipos de datos: Integers, Floats y Strings (manipulación de texto).  
•	**Miércoles:** Entrada de datos (input) y Operadores Matemáticos.  
•	**Jueves:** Estructuras Condicionales I: if, else, elif.  
•	**Viernes:** Operadores lógicos (and, or, not) y comparaciones.  
•	**Sábado (Proyecto):** "Calculadora de Notas Universitaria" que determine si un alumno aprueba según sus parciales.  
### Semana 2: Estructuras de Control y Colecciones
•	**Lunes:** Bucles Definidos: El ciclo for y la función range().  
•	**Martes:** Bucles Indefinidos: El ciclo while y control de flujo (break, continue).  
•	**Miércoles:** Listas: Métodos de agregación, eliminación y ordenamiento.  
•	**Jueves:** Diccionarios: Estructuras clave-valor (la base del manejo de datos en IA).  
•	**Viernes:** Tuplas y Sets: Diferencias y casos de uso.  
•	**Sábado (Proyecto):** "Gestor de Inventario de Laboratorio" que permita agregar, eliminar y listar componentes electrónicos.

## Módulo II: Arquitectura de Software (POO)
### Semana 3: Programación Orientada a Objetos (POO)
•	**Lunes:** Concepto de Clase, Objeto e Instancia.  
•	**Martes:** El método constructor __init__ y el parámetro self.  
•	**Miércoles:** Métodos de instancia vs. Métodos de clase.  
•	**Jueves:** Herencia: Cómo crear clases hijas (Ej: Clase Robot -> Clase RobotExplorador).  
•	**Viernes:** Encapsulamiento y Polimorfismo básico.  
•	**Sábado (Proyecto):** "Simulador de Robot": Crear una clase Robot con coordenadas X, Y que se mueva mediante métodos.

## Módulo III: Ciencia de Datos e IA (El Corazón del Plan)
### Semana 4: Manipulación de Matrices (NumPy)
•	**Lunes:** Instalación de librerías en Ubuntu (pip install numpy pandas matplotlib).  
•	**Martes:** Creación de Arrays de N-dimensiones.  
•	**Miércoles:** Operaciones vectorizadas (sumar matrices sin usar bucles for).  
•	**Jueves:** Indexación y Slicing avanzado de datos.  
•	**Viernes:** Funciones estadísticas integradas (Media, Mediana, Desviación).  
•	**Sábado (Proyecto):** "Procesador de Señales": Limpiar un set de datos numéricos ruidosos.
### Semana 5: Análisis de Datos con Pandas
•	**Lunes:** Carga de archivos CSV y Excel.  
•	**Martes:** Limpieza de datos (Manejo de valores nulos o vacíos).  
•	**Miércoles:** Filtrado y ordenamiento de DataFrames.  
•	**Jueves:** Agrupaciones (groupby) y tablas dinámicas.  
•	**Viernes**: Introducción a Matplotlib: Gráficos de línea y barras.  
•	**Sábado (Proyecto):** "Analista de Ventas": Tomar un archivo de datos real y generar un reporte de los productos más vendidos.

•	**Lunes:** Introducción a Flet (arquitectura basada en Flutter).

## Módulo V: Inteligencia Artificial Aplicada
### Semana 7: Introducción al Machine Learning
•	**Lunes:** Concepto de Aprendizaje Supervisado vs. No Supervisado.  
•	**Martes:** Regresión Lineal: Predicción de valores numéricos.  
•	**Miércoles:** Clasificación: Árboles de decisión.
